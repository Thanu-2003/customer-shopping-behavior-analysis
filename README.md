# Customer Shopping Behavior Analysis

## 🎯 Project Overview
This project demonstrates the complete end-to-end Data Analyst workflow. Using transactional data from 3,900 purchases, I uncovered insights into spending patterns, customer segments, product preferences, and subscription behavior to guide strategic business decisions.

## 🛠️ Tech Stack
- **Data Cleaning & EDA:** Python (Pandas, NumPy)
- **Database & Analysis:** PostgreSQL (SQL)
- **Visualization:** Power BI
- **Communication & Storytelling:** Gamma
- **Version Control:** Git & GitHub

---

## 📊 The Data Analyst Workflow (Step-by-Step)

### Step 1: Data Understanding & Assessment
- Reviewed the dataset structure (3,900 rows, 18 columns).
- Identified key features: Customer demographics, purchase details, shopping behavior, and shipping types.
- Detected missing data (37 null values in the `Review Rating` column).

### Step 2: Data Cleaning & Preparation (Python)
- **Data Loading:** Imported the dataset using Pandas.
- **Initial Exploration:** Used `df.info()` and `df.describe()` to check structure and summary statistics.
- **Missing Data Handling:** Imputed missing `Review Rating` values using the median rating of each product category.
- **Column Standardization:** Renamed columns to `snake_case` for better readability and SQL compatibility.
- **Feature Engineering:** Created an `age_group` column by binning customer ages, and a `purchase_frequency_days` column.
- **Data Consistency Check:** Verified redundancy between `discount_applied` and `promo_code_used`, and dropped the latter.
- **Database Integration:** Connected the Python script to PostgreSQL and loaded the cleaned DataFrame for advanced querying.

### Step 3: Structured Data Analysis (SQL)
Performed advanced analysis in PostgreSQL to answer 10 key business questions:
1. **Revenue by Gender:** Compared total revenue generated by male vs. female customers.
2. **High-Spending Discount Users:** Identified customers using discounts but spending above the average purchase amount.
3. **Top 5 Products by Rating:** Found products with the highest average review ratings.
4. **Shipping Type Comparison:** Compared average purchase amounts between Standard and Express shipping.
5. **Subscribers vs. Non-Subscribers:** Compared average spend and total revenue across subscription statuses.
6. **Discount-Dependent Products:** Identified the top 5 products with the highest percentage of discounted purchases.
7. **Customer Segmentation:** Classified customers into New, Returning, and Loyal segments based on purchase history.
8. **Top 3 Products per Category:** Listed the most purchased products within each category.
9. **Repeat Buyers & Subscriptions:** Analyzed if customers with >5 purchases are more likely to subscribe.
10. **Revenue by Age Group:** Calculated the total revenue contribution of each age demographic.

### Step 4: Data Visualization (Power BI)
- Built an interactive Power BI dashboard to present the SQL insights visually.
- Designed intuitive charts and KPIs to allow stakeholders to easily track customer behavior and revenue metrics.

### Step 5: Communication & Storytelling (Gamma)
- Created a professional, interactive presentation using Gamma.
- Translated technical findings into a clear, non-technical narrative for business stakeholders, summarizing the methodology, key insights, and strategic recommendations.

## 💡 Key Business Recommendations
Based on the end-to-end analysis, I recommend the following strategic actions:
1. **Boost Subscriptions:** Promote exclusive benefits to convert non-subscribers into loyal members.
2. **Customer Loyalty Programs:** Reward repeat buyers to accelerate their movement into the "Loyal" segment.
3. **Review Discount Policy:** Balance sales boosts with profit margin control for discount-dependent products.
4. **Product Positioning:** Highlight top-rated and best-selling products in targeted marketing campaigns.
5. **Targeted Marketing:** Focus ad spend on high-revenue age groups and users who prefer express shipping.

## 🚀 How to Run This Project
1. Clone the repository.
2. Open the Python notebook in `/python_notebooks` to view the data cleaning and EDA process.
3. Run the SQL scripts in `/sql_queries` using your PostgreSQL database.
4. Open the Power BI file in `/dashboard` to explore the interactive visuals.
5. View the Gamma presentation link or exported PDF in `/presentation` for the executive summary.
